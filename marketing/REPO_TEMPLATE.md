## Golden rules

- One subreddit per week per repo. Never the same title twice.
- Reply to every comment for the first 24h — engagement is the algorithm.
- Never fake engagement. Never promise results you can't show (especially money).
- If a repo has no README/description, fix that BEFORE posting (template in REPOS.md).
